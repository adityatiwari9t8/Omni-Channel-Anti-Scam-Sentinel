# Model card: Sentinel email risk classifier

- **Model/version:** TF-IDF unigram logistic regression plus deterministic URL/sender/payment rules, v0.2.0.
- **Training source:** `Dizzzy0x00/LLMGen-Phishing-Email-Dataset`, English `GPT_Phishing_Email_dataset.csv`; Apache-2.0. Dataset card says messages were generated by LLMs. Source: [Hugging Face dataset](https://huggingface.co/datasets/Dizzzy0x00/LLMGen-Phishing-Email-Dataset).
- **Training split:** stratified 80/20, `random_state=17`; 2,996 training and 750 held-out examples from the English CSV. Model exported to `src/weights.json` by `eval/text/train_model.py`.
- **Held-out corpus metrics:** accuracy 99.73%; phishing precision 99.80%; phishing recall 99.80%; false-positive rate 0.39%; ROC AUC 0.99999. Confusion matrix: TN 253, FP 1, FN 1, TP 495. These high scores reflect a random split of a synthetic LLM-generated corpus and must not be read as real-world or cross-source performance.
- **Features/runtime:** lowercase unigram TF-IDF (L2-normalized) plus logistic regression. Sparse JSON vocabulary/IDF/coefficient weights; plain TypeScript; no network, WASM, or runtime dependencies.
- **Decision:** model probability is combined with local deterministic rules; interface labels use risk thresholds 0.35 and 0.65. Those product thresholds have not been calibrated against real mail.
- **Known limitations:** English only; synthetic source distribution; duplicate/near-duplicate leakage across a random split is possible; real campaigns, languages, benign urgency, and new attack styles are not represented adequately. Treat results as prototype evidence only.
- **Reproduction:** provide the English CSV locally and run `python eval/text/train_model.py path/to/GPT_Phishing_Email_dataset.csv`. The CSV is not bundled; the exporter writes the two tracked model/evaluation artifacts.
